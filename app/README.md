### AI speech chat

Voice messages are sent from the app to `POST /api/speech/chat`, which forwards audio to your speech backend. Copy `.env.example` to `.env.local` and set:

```bash
SPEECH_SERVICE_URL=http://localhost:8080
```

The downstream service must accept `multipart/form-data` with field `audio` at `POST {SPEECH_SERVICE_URL}/chat` and return JSON:

```json
{ "reply": { "text": "Assistant reply text" }, "messageId": "optional" }
```

If `SPEECH_SERVICE_URL` is unset, the API returns `503` and the chat UI shows a send error (no canned replies).
